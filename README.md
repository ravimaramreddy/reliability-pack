# reliability-pack

One hand-over file that gives an AI coding agent reliable working habits: read the precedent before it acts, show proof before it says "done", and four supporting skills (break-it review, lessons, blast radius, pause and pickup).

## Use

1. Open [`reliability-pack.md`](reliability-pack.md) and copy it.
2. Give it to the agent in your environment and say: "Read this file and set it up here."
3. Answer its one question (where to install).
4. Start a new session. New skills load only in a new session.

The file gives the intent and the parts that must hold. The agent fits the wording, the tools, and the layout to its own environment.
